🔍 filter()

Array se sirf wahi elements select karta hai jo condition satisfy karte hain.

⚡ map()

Har element ko transform karta hai aur naya array return karta hai.

🎯 reduce()

Pure array ko accumulate karke ek single final value (e.g., total) banata hai.

Task 1 – Data Transformation with map() and filter()

Prices me se 250 se badi values filter karo, fir unpar 10% discount lagao.

const prices = [120, 250, 300, 450, 600];

// 1. Filter prices greater than 250
const filteredPrices = prices.filter(price => price > 250);

// 2. Apply 10% discount using map()
const discountedPrices = filteredPrices.map(price => price * 0.90);

Task 2 – Calculate Total Expense with reduce()

Expenses array se reduce() ka use karke total expense calculate karo.

const expenses = [
    { category: "Food", amount: 300 },
    { category: "Transport", amount: 150 },
    { category: "Shopping", amount: 400 }
];

// reduce() se total amount nikalna
const totalExpense = expenses.reduce((total, item) => total + item.amount, 0);
// Output: "Total Expense: ₹850"

Task 3 – Combine map(), filter(), reduce()

Passing scores (>=50) filter karo, +10 bonus marks jodo, aur total nikaalo.

const scores = [45, 80, 90, 35, 60, 75];

// Method Chaining: filter -> map -> reduce
const totalScore = scores
    .filter(score => score >= 50)       // [80, 90, 60, 75]
    .map(score => score + 10)           // [90, 100, 70, 85]
    .reduce((sum, score) => sum + score, 0); // 345

🏆 Mini Challenge – Student Score Analyzer

Paas hone wale students (marks ≥ 50) ko filter karo, +5 bonus do, unke marks dikhao, aur class average calculate karo.

const students = [
    { name: "Aman", marks: 85 },
    { name: "Sara", marks: 42 },
    { name: "Riya", marks: 68 },
    { name: "John", marks: 49 }
];

// 1. Filter passing (>= 50) & add +5 bonus
const passed = students
    .filter(s => s.marks >= 50)
    .map(s => ({ name: s.name, marks: s.marks + 5 }));

// 2. Class average
const avg = passed.reduce((sum, s) => sum + s.marks, 0) / passed.length;
