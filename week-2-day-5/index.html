Task 1 – Initialize & Push Portfolio Repo

Apne existing Personal Portfolio Project folder me Git initialize karke remote GitHub repository par push karne ke commands:

git init Initialize a new Git repository locally
git add . Stage all portfolio files for commit
git commit -m "Initial Portfolio Commit" Save snapshot with commit message
git branch -M main Set default branch to 'main'
git remote add origin https://github.com/sahil-kelkar/portfolio.git Link local repository to remote GitHub URL
git push -u origin main Push local commits to GitHub repository

Task 3 – Create & Merge a Feature Branch

New feature branch banana, changes push karna, aur Pull Request (PR) merge karne ka workflow:

git checkout -b feature-projects Create and switch to new branch
git add . Stage your modified HTML/CSS files
git commit -m "Added projects section" Commit changes on feature-projects branch
git push origin feature-projects Push feature branch to remote GitHub
